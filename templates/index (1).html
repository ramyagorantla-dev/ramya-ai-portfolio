CloudPilot: AI-Powered Cloud Troubleshooting Assistant

Problem: Engineers lose time searching docs for fixes to errors like CrashLoopBackOff, HTTP 503 or failed VM connections, and generic chatbots often invent answers.

What I built: A RAG assistant that embeds the question with Sentence Transformers, ranks a troubleshooting knowledge base with a hybrid score (semantic similarity plus keyword, service and error-code signals), filters weak matches, and has Gemini answer only from the retrieved sources. Off-topic questions are detected and declined.

✓ Result: retrieval passed 5/5 evaluation scenarios, including correctly rejecting an off-topic question. The evaluation script runs without spending API quota.
